# 紅海釣具 — 視覺與互動設計綱要

> 本文件是純文字的設計規範（Design Spec），用於指導整站重建。
> **不含任何圖片**；所有 mockup、產品圖、形象圖留待未來生成。
> 規範以「現代戶外裝備品牌」為基調，貼合磯釣 / 船釣 / 灘釣 / 路亞 / 釣蝦 等多元釣具型態。

---

## 1. 設計理念（Design Principles）

> **客群定位**：成功人士的休閒釣魚生活。
> 不做平價電商風、不做花車感、不做廉價特價貼。
> 目標品牌氣質：Orvis × Monocle × YETI Premium × Patek Philippe 的混血。

| 原則 | 內容 |
| --- | --- |
| **節制（Restraint）** | 留白優先、顏色少、字體少、動畫少。多即是少 |
| **編輯感（Editorial）** | 像高端雜誌而非電商；攝影為主、文案為輔、商品為主角 |
| **暖色而不冰冷** | 米色 + 暖炭 + 黃銅金，**不用冰冷的海藍青/螢光橘** |
| **襯線氣質** | 標題用襯線字（雜誌感、世襲感）；內文保留無襯線好讀 |
| **昂貴感** | 商品卡無框、價格不誇張、特價標收斂為小斜體 `Sale` |
| **跨裝置一致** | 手機桌機同一份視覺語言、不另開花俏行動版 |
| **可長期維護** | 商品資料來自定時 DB → JSON，UI 不可與 schema 強耦合 |

## 2. 色彩系統（Color Tokens）

> **設計方向 v0.3：Premium / Editorial**
> 主色 = **米色紙感 + 暖炭墨黑 + 黃銅金**。
> 全面**棄用**舊版的海藍青 (`#0E7C86`) 與螢光橘 (`#E15D2F`)。

### 2.1 紙與墨（Paper & Ink）
雜誌書感的暖色基底，是整站背景基調。

| Token | HEX | 用途 |
| --- | --- | --- |
| `--cream-050` | `#F5F1E8` | 主背景（淺色模式預設）｜溫米紙感 |
| `--cream-100` | `#EEE8DA` | 卡片/容器底色（淺色模式） |
| `--cream-200` | `#E2DAC8` | 分隔線、極輕量邊框（淺色模式） |
| `--ink-900` | `#1A1816` | 主背景（深色模式預設）｜暖炭近黑、略偏咖啡 |
| `--ink-800` | `#25211D` | 卡片底色（深色模式） |
| `--ink-700` | `#332E28` | hover 容器（深色模式） |
| `--ink-500` | `#5C5249` | 次級文字（深色模式） |
| `--ink-300` | `#A89D8E` | 輔助文字（深色模式） |
| `--ink-100` | `#F5F1E8` | 主要文字（深色模式）= 米色 |
| `--ink-text` | `#2A2622` | 主要文字（淺色模式）｜不用純黑、暖一點 |
| `--ink-text-soft` | `#5C5249` | 次級文字（淺色模式） |

### 2.2 黃銅金（Brass）— 品牌主色
取自老式釣具魚鉤、刻度、雕版漆面的金屬反光。**鏈接、按鈕、focus、品牌 mark**。

| Token | HEX | 用途 |
| --- | --- | --- |
| `--brass-500` | `#A88862` | 品牌主色｜鏈接、CTA 邊框、mark |
| `--brass-700` | `#7B6242` | hover、按下、深底上的對比版 |
| `--brass-300` | `#C9B292` | 淺底上的次要強調 |
| `--brass-soft` | `#F0E6D2` | tag 背景、選中態 |

### 2.3 深酒紅（Ember Wine）— 唯一警示/特價色
舊版鮮橘退場，改為單寧暗紅。**只用於 sale 標、限量、缺貨警示**，且樣式收斂為小斜體文字而非實心徽章。

| Token | HEX | 用途 |
| --- | --- | --- |
| `--ember-600` | `#8B2C1F` | 特價、限量小字 |
| `--ember-soft` | `#F2E2DD` | 警示底色（極少用） |

### 2.4 語義色（不變）
| Token | HEX | 用途 |
| --- | --- | --- |
| `--status-success` | `#3F7D4E` | 庫存正常、訂單完成 |
| `--status-warning` | `#A88862` | 警告（沿用 brass） |
| `--status-error` | `#8B2C1F` | 錯誤、移除 |
| `--status-info` | `#5C5249` | 資訊提示 |

### 2.5 雙模式（Light / Dark）
**Light 與 Dark 都是品牌主視覺**，不是「主+輔」。
- **Light** = 雜誌米色紙感，書本翻開的靜謐
- **Dark** = 高端 lounge 夜晚感，**暖炭黑而非冰冷 navy**
- 預設 Light（白天時段、大多數使用情境）；右上 toggle 切 Dark
- 兩種模式都用同一組標題襯線字、同一組品牌 brass，差別只在背景/文字明度
- **特價標斜體小字 `Sale` 在兩個模式都是 ember-600 紅**，不變色

## 3. 字體系統（Typography）

### 3.1 字型選擇（v0.3：襯線標題、無襯線內文）
| 用途 | 字體（候選） | 備援 |
| --- | --- | --- |
| **中文標題（h1-h3）** | **Noto Serif TC**（思源宋體） | "PingFang TC", "Songti TC", serif |
| **英文標題 / 品牌字標** | **Cormorant Garamond Italic** 或 EB Garamond Italic | "Times New Roman", Georgia, serif |
| **中文內文** | Noto Sans TC | system-ui, "PingFang TC", "Microsoft JhengHei" |
| **英文/數字內文** | Inter | -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto |
| **數字（價格）** | Inter Tabular Nums | — |
| **uppercase nav / eyebrow / label** | Inter，字距 0.18em | — |

避免使用：標楷體、新細明體、Comic Sans、粗壯展示字（Bebas/Anton 已退場）。

### 3.2 字級階層（rem，以 16px 為基準）

| Token | rem | px | 用途 |
| --- | --- | --- | --- |
| `--text-xs` | 0.75 | 12 | 標籤、breadcrumb |
| `--text-sm` | 0.875 | 14 | 輔助說明、表單 hint |
| `--text-base` | 1.0 | 16 | 內文 |
| `--text-lg` | 1.125 | 18 | 商品名（列表卡片） |
| `--text-xl` | 1.375 | 22 | 區塊標題 |
| `--text-2xl` | 1.75 | 28 | 商品名（詳情頁） |
| `--text-3xl` | 2.25 | 36 | 頁面主標 |
| `--text-display` | 3.0 | 48 | 首頁 hero、品牌語句 |

### 3.3 字重
- 中文：300（情境）、400（內文）、500（強調）、700（標題）
- 英文：400 / 500 / 600 / 700

### 3.4 行高
- 標題：1.2
- 中文長文：1.7
- 英文長文：1.5
- 商品名（一行截斷）：1.3

## 5. 元件規範（Components）

### 5.1 Header（頂部導航）
- 高度：64px（桌機）/ 56px（手機）
- 結構（左→右）：Logo + 搜尋框 + Nav（11 大類） + 訂單查詢 + 會員 + 購物車徽章
- 滾動時：scroll > 80px 加入 `backdrop-filter: blur(12px)` 與細邊
- 11 大類在桌機橫排，手機收進漢堡選單
- 子分類（每大類多達 18 個子分類）用 mega menu 三欄展開，hover 200ms 漸出

### 5.2 Logo / 品牌語
- 文字商標：「紅海釣具」+ 英文輔助 `FishTool.tw`（取原站既有品牌字標，斜體小字、低調 .tw 域名感）
- mark：魚鉤輪廓 + 海浪線條（modern 線稿，呼應原站紅色手寫 + 小魚但更乾淨）
- 品牌語（hero 用）：「探索無限可能 釣出你的精彩」

### 5.3 SearchBar
- 圓角 24px、placeholder：「搜尋釣竿、捲線器、品牌、編號」
- 桌機：頂部 nav 中央寬度約 320–480px
- 手機：點擊放大鏡展開全寬 modal 搜尋
- 支援按 `Esc` 關閉、`/` 開啟（鍵盤快捷）

### 5.4 商品卡片（ProductCard）
```
┌────────────────────┐
│                    │
│   [product image]  │ ← 1:1，object-fit: contain, 背景 --ink-800
│                    │
├────────────────────┤
│ 品牌 · 編號         │ ← --text-xs --ink-300
│ 商品名稱（最多兩行）  │ ← --text-lg --ink-100
│ $1,580 (原 $1,750) │ ← 特價大字 + 原價刪除線
│ [特價] [新品]       │ ← 徽章
└────────────────────┘
```
- 整卡片可點，hover 圖片放大 1.03 倍 + 浮上陰影
- 售價（`price`）與特價（`sale_price`）若相等只顯示一個
- 「滿千免運」之類的活動標 → 用小型 tag 顯示在卡片右上

### 5.5 商品詳情頁（ProductDetailLayout）
桌機版：左 60% 圖庫 / 右 40% 資訊
```
┌──────────────────────────────────┬────────────────────┐
│                                  │ 麵包屑              │
│         [主圖 1:1]                │ 品牌 · 編號 DM-xxx  │
│                                  │ 商品名稱（h1）       │
│ [縮圖 1][縮圖 2][縮圖 3] …        │ ★ 評等（如有）       │
│                                  │ ─────────────       │
│         說明（h2 + 內文）          │ $ 售價 / 特價       │
│                                  │ 規格選擇（如尺寸）    │
│         規格表（spec table）       │ 數量 + 加入購物車    │
│                                  │ 收藏 / 分享          │
│         相關商品                   │ 庫存 / 配送資訊      │
│                                  │ FAQ 摺疊            │
└──────────────────────────────────┴────────────────────┘
```
手機版：圖庫橫滑、資訊在下、加入購物車 sticky 至底部。

### 5.6 麵包屑（Breadcrumb）
`首頁 / 釣竿 / 釣竿-磯釣竿 / 《SHIMANO》(特價) 17 HOLIDAY ISO`
- 字級 `--text-xs`、`--ink-300`、最後一節 `--ink-100`
- 分隔符用 `/` 而非 `＞`（原站用全形 ＞，現代版改半形）

### 5.7 分類側邊導航（CategorySidebar）
- 11 大類為 accordion，當前大類預設展開
- 子分類用條列、選中態加左側 4px 寬 `--brand-tide` 色條
- 桌機分類頁：左 sidebar 200px + 右商品格線
- 手機分類頁：頂部水平捲動 chip bar

### 5.8 篩選與排序（Filter & Sort）
- 排序：價格 ▲ / 價格 ▼ / 上架新到舊 / 上架舊到新
- 篩選（建議新增）：品牌、價格區間、是否有特價、是否有庫存
- 篩選 chip 顯示在格線上方，可一鍵清除

### 5.9 按鈕（Button）
| 變體 | 用途 | 樣式 |
| --- | --- | --- |
| Primary | 加入購物車、結帳 | 填色 `--brand-tide`、白字 |
| Secondary | 取消、返回 | 透明 + 邊框 `--ink-500` |
| Ghost | 列表內的次要操作 | 純文字、hover 加底 |
| Danger | 刪除、移除 | 填色 `--status-error` |
| Pill | 篩選 chip | 圓角 999、邊框 + hover 換底 |

- 高度：lg 48 / md 40 / sm 32
- 內距：橫向 16-24
- focus ring：2px outline `--brand-tide` + 2px offset

### 5.10 表單（Form）
- input 高度 40 / 圓角 6 / 邊框 1px `--gray-300`
- focus：邊框 `--brand-tide`、外加 2px outline
- 錯誤訊息：紅字 12px、icon `!` 在前
- 必填用 `*` 紅色標示，hint 顯示在 label 旁灰字

### 5.11 徽章 / 標籤（Badge）
- 規格：高 20、圓角 4、字級 11、字重 600
- 變體：特價、新品、現貨、預購、限量、品牌專區

### 5.12 通知（Toast）
- 右上角彈出（桌機）/ 底部（手機）
- 自動消失 3 秒、可手動關閉
- 變體：成功 / 警告 / 錯誤 / 資訊

### 5.13 Empty State / Loading
- 空狀態用線稿插畫（之後再產生），文案要釣具相關（例：「目前還沒有上架，先去看看其他釣竿」）
- Loading：骨架屏（skeleton），不是 spinner

### 5.14 Footer
- 三欄：客服資訊 / 商店資訊（聯絡 / 地址 / 營業時間）/ 社群連結（FB 社團）
- 底列：版權、隱私、條款
- 配色用 `--ink-900`、文字 `--ink-300`，連結 hover 轉 `--ink-100`

## 6. 頁面範本（Page Templates）

### 6.1 首頁
1. **Hero**（全寬，60vh）：標語 + CTA「逛全部釣竿」
2. **11 大類入口**（icon grid，每類一個圖示 placeholder）
3. **熱銷新品**（商品卡片橫滑，6–8 件）
4. **特價精選**（商品卡片網格，最多 12 件）
5. **品牌專區**（品牌 logo 牆 placeholder：SHIMANO、DAIWA、上興、AGK、HEXING、pokee、gamakatsu …）
6. **內容區**（如新手指南、保養知識，可選）
7. **Footer**

### 6.2 分類頁
- 麵包屑 + 分類名 + 商品總筆數
- 左 sidebar（11 大類）/ 右商品網格 + 分頁
- 排序與篩選列在格線正上方
- 商品超過 80 筆使用分頁或無限滾動（建議「載入更多」按鈕）

### 6.3 商品詳情頁
- 見 §5.5
- SEO：`<title>` = 品牌 + 編號 + 商品名、`<meta description>` = 商品名 + 規格 + 價格

### 6.4 搜尋結果頁
- 與分類頁版型一致，標題改為「搜尋『關鍵字』的結果」

### 6.5 訂單查詢頁
- 簡單表單：訂單編號 + 手機末四碼 / Email → 查詢結果卡片

### 6.6 會員 / 註冊 / 登入
- 二欄式：左品牌氛圍 placeholder / 右表單
- 行動裝置：表單置中

### 6.7 FAQ
- 折疊面板（accordion），按類別分組
- 搜尋框、可直接展開全部

### 6.8 詢問 / 客服
- 表單 + 客服聯絡資訊 + LINE/Facebook QR placeholder
- 表單欄位：姓名、聯絡方式、商品編號（選填）、訊息

## 7. 動效與互動（Motion）

| 場景 | 動效 |
| --- | --- |
| 連結 hover | `transition: 150ms ease-out` 顏色變化 |
| 卡片 hover | `transform: scale(1.02)` + 陰影漸入 200ms |
| Modal 開啟 | 透明度 0→1、translateY 8px→0，200ms |
| 分頁/篩選變更 | 商品格線淡入 200ms，先骨架後內容 |
| Toast | 滑入 200ms、滑出 200ms |
| 全域 | 尊重 `prefers-reduced-motion`，全部動效收斂為瞬時 |

## 8. 無障礙（Accessibility）

- 對比度：正文 ≥ 4.5:1、大字與圖示 ≥ 3:1
- 所有圖片 `alt`，裝飾性圖 `alt=""`
- 鍵盤可達：所有可點元素皆可 Tab，focus 樣式明確（不可 `outline: none` 不補）
- 表單錯誤要文字 + 圖示，不只靠顏色
- 中文閱讀方向左到右；行寬不超過 80 中文字
- 連結加入語意 aria-label（特別是純圖示連結）

## 9. 圖像方向（Imagery Guidelines）

> **本階段不產任何圖**，以下作為未來生成圖時的方向：

### 9.1 商品圖
- 一致背景：純色或極簡漸層（淺灰 / 深海色）
- 角度：主圖正側、可加上 30° 透視作補充
- 比例：1:1（列表）+ 4:5（詳情主視覺）
- 細節圖：紋路、配件、刻度近拍
- 不要：擺在木桌、雜物堆、傳統閃光大背景

### 9.2 形象圖 / 情境圖
- 主題：磯岸夜釣、船釣甲板、晨曦灘釣、夜市釣蝦場
- 色調：自然光、低彩度、可帶霧氣或波光
- 構圖：人物背影或局部、強調器材與環境關係
- 不要：刻意擺拍、戴著太陽眼鏡比讚的合成照

### 9.3 圖示（Icon）
- 線稿風格、stroke 1.5px、圓角端點
- 套件：Lucide / Phosphor 風格優先
- 11 大類各一圖示（之後再產），統一視覺

### 9.4 Hero / 首頁主視覺
- 大畫面、地平線在 1/3 處、留出文字疊放區
- 海面為主、避免直射陽光在鏡頭

## 11. 暗色模式 / 亮色模式

## 12. 效能與技術約束（給未來實作參考）

- **SSG**：Astro（Content Collections 直接吃 JSON）
- **CSS**：原生 CSS Variables + 一份 `tokens.css`（不引入 Tailwind 以免設計被框架制約；之後想換可換）
- **互動**：純 vanilla JS（IIFE 模組化）或 Astro Islands（如即時庫存）
- **圖片**：使用 `<img loading="lazy" decoding="async">`、未來引入 `astro:assets` 自動產生 WebP/AVIF
- **字型**：`font-display: swap`、preconnect Google Fonts、把 Noto Sans TC 子集化或自託管
- **可長期維護**：所有顏色、字級、間距走 token，不在元件內硬編碼
